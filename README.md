# Social Rehabilitation and Training Association — Website (Team Project)

Arabic (RTL) website for a non-profit association in Gaza, built with **React + Vite + Tailwind CSS**.
I worked on it as a **Front-End Developer** at the association (May – Aug 2025) together with the team.

## Features
- Home with news slider, programs, goals, principles, strategic plan, annual reports, partners and board
- News and articles with detail pages and search
- Programs with detail pages
- Media library: photo and video albums with detail views
- Certificates section
- Job application form and contact page
- Admin dashboard (front-end demo): add and manage news and programs
- Responsive layout with sidebar and scroll-to-top

## Tech
React · Vite · Tailwind CSS · React Router · Context API

## Note
Real photos (which showed children at the association's activities), board members' names and a sample file were replaced with placeholders for privacy. The admin login is a front-end demo only.

## Run
```bash
npm install
npm run dev
```
